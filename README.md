# Bash Authentication System 

A simple authentication system developed with Bash scripting to practice Linux terminal usage, user input handling, conditional statements, and basic security concepts.

##  About The Project

This project is a beginner-level Bash scripting application created during my Linux and cybersecurity learning journey.

The purpose of this project is to understand how basic authentication logic works by creating a simple username and password verification system using Bash.

##  Features

- User input handling
- Username and password verification
- Hidden password input
- Conditional statements with Bash
- Loop structures
- Basic terminal interaction

## Technologies Used

- Bash Shell
- Linux Ubuntu
- Terminal Commands
- Shell Scripting
